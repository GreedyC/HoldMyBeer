# Roadmap

This roadmap separates the working preview from ideas that need design and evidence. Issues and pull requests are welcome; no item is a promise of release timing.

## Available in the preview

- Browser-picker screen capture implemented; manual selection compatibility pending. Imported video and playback verified.
- Manual teaching notes, answers, and editable procedure steps.
- A Playwright run against the bundled browser fixture, with a retained-result check.
- An opt-in Hermes scaffold with a read-only local status tool.

## Starter tasks

1. **Recorder clarity:** document browser permission prompts and accessible start/stop states.
2. **Procedure examples:** write one sanitized fixture workflow with clear goals and observable checks.
3. **Failure explanations:** improve the wording shown when a fixture checkpoint fails.
4. **Accessibility review:** try the teaching interface with keyboard-only navigation and report barriers.
5. **Hermes compatibility note:** verify the scaffold against a stated Hermes version and document the result.

## Later exploration

- Structured browser observations aligned with recorded video.
- Optional, explicitly configured AI analysis of bounded excerpts.
- More browser adapters and stronger replay evidence.
- Procedure export/import with validation and local verification.
- Carefully scoped publishing workflows, only after separate authorization and real-account acceptance.

These later ideas are not implemented. There is no current AI video analysis or live social publishing.
